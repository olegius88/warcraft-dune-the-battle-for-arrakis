# src/config — все параметры проекта

Здесь объявлены константы, на которые ссылается остальной код. Правило проекта
([CLAUDE.md](../../CLAUDE.md)): **число, строка-идентификатор, путь или таблица, которые можно
настроить или с которыми легко ошибиться, живут здесь**, а не прямо в коде. В модулях
`src/emperor`, `src/wc3` остаются только форматы файлов (смещения, магические числа
спецификаций) и логика.

| Файл | Что в нём |
|---|---|
| `paths.ts` | Пути: установка Emperor (`EMPEROR_DIR`), извлечённые данные `data/`, выходы `build/`, pjass, common.j/blizzard.j. |
| `houses.ts` | Дома: имена, коды `AT/HK/OR`, id времени выполнения, русские названия, цвета WC3, расы. |
| `scale.ts` | Пересчёт Emperor → WC3: тики в секунду, тайл, HP/урон, скорость, дальности, обзор, высоты рельефа, отступы карты, константа брони WC3. |
| `wc3.ts` | Идентификаторы WC3: коды полей объектов (`unam`, `uhpm`…), способности, стандартные юниты, декорации, предметы, наши фиксированные id, модели эффектов, иконки, тайлы, папки импорта. |
| `units.ts` | Юниты/здания: соответствие брони, типы атак (k-means), модели-заменители, вспомогательные объекты (харвест, поле специи, строитель, маркер хаба). |
| `terrain.ts` | Вид рельефа: слоты текстур, цвета миникарты, приоритет текстур в углах, слой/«без обрыва». |
| `scenery.ts` | Объекты карт Emperor: что пропускать, что считать бочками/деревьями/обломками/ящиками/гражданскими домами. |
| `battle.ts` | Бой за территорию: шаблон базы противника, состав войск ИИ, специя, стартовые деньги, смещения появления, таймеры волн. |
| `runtime.ts` | JASS-рантайм миссии: стороны, радиусы «рядом» API Emperor, таймеры, очередь речи, ящики, ветеранство, отладочный отчёт, имена игроков. |
| `movies.ts` | Ролики: частота и размер кадров, качество JPEG и MP3, пути в архиве, область экрана, таблица «событие хаба → события MOVIES.TXT» по Домам. |
| `campaign.ts` | Кампания: 33 территории, точки прыжка, фазы и тех-уровни, виды миссий, ключи game cache (с готовыми JASS-литералами `J_CACHE_*`), имена карт, тексты экрана кампании. |
| `story.ts` | Сюжетные миссии домов: какой скрипт на какой карте; обучение. |
| `hub.ts` | Карта «Арракис»: размер, раскладка графа территорий, подписи, линии, камера; превью рельефа. |

## Нюансы

- Значения, попадающие в JASS, подставляются через `real()` / `str()` из `src/wc3/jass.ts`:
  `real(3)` даёт `3.0`, `str('emp')` даёт `"emp"`, поэтому вынос в константы не меняет
  сгенерированные карты (проверено побайтной сверкой всей кампании).
- Пути WC3 с обратными слешами (`EFFECT`, `ICON`, `IMPORT_DIR`) записаны с одинарными `\` в
  значении; `str()` экранирует их для JASS.
- Модули конфигурации не зависят от кода `src/emperor`, кроме типов (`RulesObject` в `units.ts`).
