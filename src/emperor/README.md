# src/emperor — Emperor: Battle for Dune → кампания Warcraft III

Читает **установленную у пользователя** игру (по умолчанию `G:\Games\Emperor`, переопределяется
`--game` или `EMPEROR_DIR`). Промежуточные данные — в `data/emperor/` (в `.gitignore`, не распространяются).

## Устройство кампании

- Кнопки экрана кампании: «Обучение», «Атрейдесы», «Харконнены», «Ордосы». Кнопка дома запускает
  его стартовую миссию; дальше всё идёт через хаб «Арракис» (`<дом>_Hub.w3x`) и `ChangeLevel`.
- Карты боёв: `<дом>_A<nn>.w3x` (атака территории nn), `<дом>_D<nn>.w3x` (оборона). В карте лежат
  скрипты всех фаз для этой территории; нужный выбирается по фазе из кэша. Захват вражеской столицы —
  принудительные миссии из `Forced Missions.txt` (`*Jump_reb*`).
- Сюжет: `<дом>_S_Heighliner`, `_S_HomeDefence`, `_S_Home<враг>` (вторжение на родной мир), `_S_End`.
- Состояние — game cache `EmperorCampaign.w3v`, раздел `emp`: владельцы `own1..33`, `phase`, `tech`,
  `captured`, передача боя `pendterr/pendkind/pendenemy/pendfrom`, результат `result/resultkind/resultterr/outcome`.
- Вне кампании (карта открыта отдельно) бой заканчивается обычным окном победы — `ChangeLevel`
  вне кампании роняет игру (проверено в 1.31 и 3.0).

## Формат скриптов `.tok` (восстановлен 2026-10-07)

Публичного описания нет. Всё ниже проверено на всех 228 скриптах (`test/emperor-tok.test.ts`).

- Файл: `uint32 длина тела`, `uint32 число строк`, затем строки, каждая заканчивается `0x00`.
- В строке ASCII — литералы, байты `>= 0x80` начинают токены; числа в токенах — две base-128 цифры
  с выставленным старшим битом, младшая первой.
  - `80 lo hi` — запись таблицы токенов (`Game.exe`, записи по `0x5C` байт от `ModelTick`).
  - `81 n` — переменная. `82 lo hi` — тип объекта (сквозная нумерация `*Types` из `Rules.txt`).
  - `83 lo hi` — сообщение (`[MissionMessages]` всех строковых файлов в алфавитном порядке).
  - `84 lo hi` — подсказка (`[ObjectTips]`).
- Скрипты скомпилированы под английские таблицы архива: номер → ключ там, текст — из русских по ключу.
- Причуды оригинальных скриптов и как они переводятся — в комментариях `translate.ts`.

## Карты (`MAPS0001/0002`)

- Папка на карту: `test.xbf`, `test.CPF`, `test.CPT`, `test.lit`, `texture.dat`, `map.inf`.
  32 мировые единицы на тайл. `MAPINFO.INI` — тип мира (Arrakis, Heighliner, Caladan, Draconis, GiediPrime).
- `test.xbf`, тег `0x05 GameElements`: дерево точек `Base/{Primary,Secondary,Default}`,
  `Mission/Script1..6`, `MoreScripts*/Script7..24`, `Resource/Spice`, `Entrance/Connected_Entrance`
  (tag = номер соседней территории, 99 — нейтральный), `AI_Assembly/tactic`.
- Тег `0x07` — размещённые объекты: владелец 1 — обороняющаяся сторона карты (на сюжетных картах —
  целые базы и войска), 2/3 — окружение (деревья, дома, бочки, обломки, ящики).
- Тики скриптов: 25 в секунду: таймеры «через 2/1 минуту» в `ATP1D18GN` и пять комментариев
  `ai_difficulty.ini` («UnitDelay=875 // 35 seconds»…); два комментария `Rules.txt` дают 20 и считаются
  оставшимися от прежней частоты ([src/config/scale.ts](../config/scale.ts)).
