# tools — запуск Warcraft III для тестов

Задача: прогонять сгенерированные карты в настоящем клиенте **без ввода пароля** и **не занимая
мышь/клавиатуру пользователя**.

| Файл | Назначение |
|---|---|
| `run-wc3.ps1` | Копирует карту в `build\test\Current.w3x`, запускает игру через Battle.net, ждёт, печатает код выхода, новые файлы `CustomMapData` и хвост `War3Log.txt`. |
| `wc3-key.ps1` | Отправляет окну игры нажатие клавиши через `PostMessage` (без фокуса). Нужно, чтобы пройти экран «нажмите любую клавишу». |
| `wc3-click.ps1` | То же для клика мышью (без движения настоящего курсора). |
| `run-wc3-classic.ps1` | Запуск карты в классическом 1.31.1 (`G:\Games\Warcraft III`) — без Battle.net и пароля. **Основной способ тестирования.** Сторож на всё время игры: возвращает фокус пользователю и снимает ограничение курсора (см. ниже). `-FramesPrefix` — кадры для GIF, `-Trace` — журнал срабатываний сторожа. |
| `test-maps.ps1` | Несколько карт подряд: статус, отладочный отчёт миссии, снимок `build\test\shots\<карта>.png` + `.jpg` (1280 px, для чата), с `-Gif` — `.gif` (кадр каждые 3 с). |
| `make-gif.js` | Кадры → GIF (`gifenc` + `pngjs`, без ffmpeg: ярлык WinGet на ffmpeg на этой машине битый). |
| `wc3-window.ps1` | Окно игры назад без активации / снимок окна через `PrintWindow` (работает, когда окно закрыто другими). |

## Мышь и фокус (проверено 2026-10-07, 1.31.1)

- В конце загрузки карты игра ограничивает курсор своим окном (`ClipCursor`), **даже когда окно не
  активно**. `confinemousecursor=0` в `War3Preferences.txt` этого не отменяет (проверено замером
  `GetClipCursor`, файл возвращён к исходному значению 2).
- Поэтому `run-wc3-classic.ps1` каждые 30 мс проверяет `GetClipCursor` и, если игра не на переднем
  плане, снимает ограничение (`ClipCursor(NULL)`); каждые 240 мс уводит окно игры назад, если оно
  стало активным, и возвращает фокус окну пользователя. Итог печатается строкой `watchdog: ...`.

## Что принимает фоновый ввод (`PostMessage`)

| Клиент | Клавиши | Клики |
|---|---|---|
| Reforged 3.0 | только экран «нажмите любую клавишу» | нет |
| Classic 1.31.1 | меню (S — «Один игрок», U — «Доп. кампании», G — «Сражения», Enter, Esc, стрелки/Home в списках) | списки и обычные кнопки — да; **кнопки миссий на экране кампании — нет** (нужен настоящий курсор) |

## Разовая настройка (сделано 2026-10-07 с разрешения пользователя)

`%APPDATA%\Battle.net\Battle.net.config`, раздел `Games.w3`:

```json
"AdditionalLaunchArguments": "-windowmode windowed -loadfile \"I:\\_Other\\warcraft-dune-the-battle-for-arrakis\\build\\test\\Current.w3x\""
```

- Править файл только при **закрытом** Battle.net — иначе клиент перезапишет его из памяти.
- Резервная копия до правки: `%APPDATA%\Battle.net\Battle.net.config.bak-warcraft-dune`.
- Пока аргумент стоит, обычный запуск WC3 из Battle.net тоже откроет тестовую карту. После разработки
  удалить поле (закрыть Battle.net, удалить `AdditionalLaunchArguments`, запустить снова).

## Почему так

- `Warcraft III.exe -launch -loadfile ...` напрямую показывает экран входа Battle.net при каждом запуске
  (с `-uid w3` тоже).
- `Battle.net.exe --exec="launch W3 <args>"` дополнительные аргументы игре не передаёт.
- Результат проверок карты пишет сам скрипт карты через `PreloadGenEnd` в
  `Documents\Warcraft III\CustomMapData\DuneSmoke\*.pld`.
